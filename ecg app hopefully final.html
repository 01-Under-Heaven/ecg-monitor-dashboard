Connect to device
Enter your ECG Monitor's Wi-Fi IP address (default 192.168.4.1 if connected directly to its access point) and click Connect. This requires your device to be on the same network as the ECG Monitor, and works best when this page is opened without HTTPS restrictions — a secure (https) page like this one's GitHub Pages link will usually block the connection for security reasons, since the ECG Monitor serves plain, unencrypted data. If that happens here, this same page opened as a local file, or the ECG Monitor's own built-in dashboard, will connect successfully.
